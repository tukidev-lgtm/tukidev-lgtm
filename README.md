✨ Características


Diseño temático con paleta morado oscuro + dorado.
Sección de proyectos con efecto en el hover/focus (revela el contenido real debajo de un parche placeholder)
Cards de proyectos pendientes.
Hero con luciérnagas/llamas animadas, cada una con su propio timing de encendido y apagado
Totalmente responsive (mobile-first)
Accesible: navegación por teclado en las cards, prefers-reduced-motion respetado, foco visible



🛠️ Stack


HTML5 semántico
CSS3 (variables custom, Grid, Flexbox, animaciones con @keyframes)
JavaScript vanilla (sin frameworks ni dependencias)
Tipografía: Cabin Sketch + Work Sans (Google Fonts)
